## 怎么判断是不是真的跑路

官网打不开，**不一定**是跑路。很多时候只是域名被封、换了新地址，节点照常能用。按下面的顺序看：

1. **节点还能不能用？** 节点能用、只是官网打不开，多半是换域名，去机场的 Telegram 频道或你注册时的邮箱找新地址。
2. **公告渠道还在不在？** Telegram 频道、群组还在正常发消息，说明还在运营。
3. **持续了多久？** 官网、节点、客服、公告**全部**失联超过一周，才比较可能是真的跑路。

**跑路前常见的征兆**（单独一项不一定，几项同时出现要小心）：

- 突然推出远低于市场价的两年付、三年付、终身套餐，拼命催续费
- 工单、客服好几天没人回
- 节点大面积掉线，却没有任何公告
- 频繁换域名，又没有固定的通知渠道

## 机场跑路了怎么办

- **先停止续费**，把自动扣款关掉。
- **用支付宝/微信付款的，可以试试申请投诉或退款**，成功率不高，但值得一试。
- **小心"新官网"骗局**：机场出事后，常有人冒充机场发"新地址""补偿活动"，让你重新付款。只认机场原来的 Telegram 频道和邮件通知。
- **换机场时别再买长期套餐**：先买月付用一两个月，稳定了再考虑季付、半年付。

## 常见问题

**机场官网打不开，是不是跑路了？**
不一定。先看节点能不能用，再去 Telegram 频道找公告。官网、节点、客服、公告全部失联超过一周，才比较可能是跑路。

**机场跑路了，钱能拿回来吗？**
大多数情况很难。用支付宝/微信付款的可以试着投诉，但不要抱太大希望。最好的办法是一开始就别买长期套餐。

**怎么选不容易跑路的机场？**
优先选运营时间长、有固定公告渠道的机场；先买月付；远离"终身套餐""超低价三年付"这类大促。
